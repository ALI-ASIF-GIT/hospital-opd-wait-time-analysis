# Power BI dashboard data

Pre-aggregated tables generated by [`notebooks/04_export_for_powerbi.ipynb`](../notebooks/04_export_for_powerbi.ipynb). Dashboard page images are in [`../reports/dashboard/`](../reports/dashboard).

| File | Used for |
|---|---|
| `overall_kpis.csv` | KPI cards |
| `department_summary.csv`, `triage_summary.csv`, `hourly_summary.csv`, `dayofweek_summary.csv`, `weekend_summary.csv`, `agegroup_summary.csv` | Bar / line / donut charts |
| `heatmap_data.csv` | Weekday x hour matrix (`DayOrder` column for correct sorting) |
| `model_comparison.csv`, `actual_vs_predicted.csv` | Model performance page |

For slicers and row-level filters, import `../data/processed/opd_visits_clean.csv`.
