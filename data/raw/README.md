# Raw data

Download **Hospital Wait Time Data** (`Hospital_Wait_Time_Data.csv`, 5,000 rows x 57 columns) from [Kaggle](https://www.kaggle.com/datasets/bharathreddybollu/hospital-wait-time-data) and place it here, keeping the exact filename.

The raw file is not committed to this repository. The cleaned dataset is in [`../processed/opd_visits_clean.csv`](../processed/opd_visits_clean.csv).
